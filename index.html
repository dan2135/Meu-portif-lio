Código, curiosidade

Sou desenvolvedor web com experiência prática em projetos próprios, freelas e soluções para clientes. Trabalho com HTML, CSS, JavaScript e integração com backend utilizando Python com Flask.

Já desenvolvi landing pages, FAQ dinâmico, pop-ups interativos, carrosséis de depoimentos e aplicações web como sistema de controle financeiro e chatbot. Também criei a Norden, um SaaS de atendimento pelo WhatsApp com assistente virtual, desenvolvido em React, Node.js e PostgreSQL. Sou formado em Análise e Desenvolvimento de Sistemas pela Braz Cubas e também concluí o curso de Desenvolvimento Web no IOS.

Tenho perfil autodidata, facilidade para aprender novas tecnologias e busco crescer como desenvolvedor front-end e full stack júnior, criando aplicações modernas, performáticas e úteis para o usuário.
